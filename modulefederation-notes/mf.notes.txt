001.why process.nextTick() is faster than setImmediate() ?

 process.nextTick()  Executes Before I/O phase or timer events the Event Loop in microTaskQueue

 setImmediate()  runs after I/O phase   in the event Loop but before set TimeOut()

 sync ---  process.nextTick() ---  setImmediate()

002.how node js handles multiple CPU cores
  utilize multiple cores using the Cluster module and worker threads

003.prevent CallBack Hell In Node js
  by promises or by Async await

004.Event Loop Phases in Node.js
 Timers, Pending Call Backs, Idle/Prepare,
 poll(new I/O events),check(setImmediate), 
 close Callbacks(Clean Up tasks like Socket.On)

005.why does Await inside a loop is a bad Idea in Node.js
  instead use promise.all() for parallel execution

  because await blocks execution until a promise resolves,causing sequential Execution.

006.what happens when you call require() multiple times for the same module

  node js caches the module after the first require()

007.fs.readFile() vs fs.createReadStream()?
fs.readFile() -- loads entire fileintomemory making it inefficient for large files

fs.createReadStream() -- reads data in chunks preventing memory Overflow
